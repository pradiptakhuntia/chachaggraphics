# Project information

- Project: Chacha G Graphics website
- Server: Python with Flask
- Browser UI: HTML, CSS, and JavaScript
- Python requirement: 3.11 or newer

Website images, icons, videos, logos, and the 3D model are kept in `public/`.
The locally served Three.js modules are in `static/vendor/three/`.

To install the Python dependency and start the application, see
[README.md](./README.md).
